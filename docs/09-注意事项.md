# 09 · 注意事项

> 使用前值得先看一遍的几条。安装步骤见 [`README`](../README.md) 的 [🚀 快速开始](../README.md#-快速开始)。

---

| 项目 | 说明 |
|:----:|:-----|
| 🧩 **节点必须自己填** | `[Proxy]` 段全是占位符（`203.0.113.x` + `REPLACE_WITH_*`）。不填则 `FINAL → Proxy` 是断的 —— **所有走代理的流量都不通** |
| 🪶 **`v0` 的三点代价** | 见 [`profiles/v0.conf`](../profiles/v0.conf) 末尾。要点：黑名单误杀的功能域无人放行、AI 与日常流量合流、`Proxy` 是 `select` 不是 `smart`（节点挂了要手动切） |
| 🔄 **规则集刷新** | 全部远程 `RULE-SET` 都带 `update-interval=86400`（按天刷新）。这是**必须**的 —— 上游新收录的广告域名否则会一直命不中 |
| 🧪 **全部本地完成** | 本仓库**刻意不挂 CI / 任何自动化**（理由见 [`skill/README.md`](../skill/README.md)）—— 改完 profile 在仓库根目录跑一次 `bash skill/tests/run.sh` 即可 |
| ⚠️ **"审计全绿"不等于"配置可用"** | 本项目的审计脚本只覆盖**静态可判定**的部分。拦截效果、误杀、节点可用性必须实测 —— 这是 Egern 项目连续 5 次"脚本全绿、实测仍有问题"换来的结论 |
| 🔐 **不要把真实节点提交回来** | 本仓库是公开模板。改完本地用可以，`git push` 前跑一次阶段 3 的 `architecture.sh` —— 它会拦住非占位 IP 与未替换的凭据 |
